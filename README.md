
🧬 CodeDNA

CodeDNA is a full-stack web application designed to help developers understand, analyze, and improve their coding journey.

The project brings together a frontend and backend to provide a platform for working with coding-related data and building a personalized developer experience.

🚀 Project Overview

CodeDNA is built as a full-stack application with a clear separation between the client and server:

- Frontend — User interface and client-side functionality
- Backend — Server-side logic, APIs, and application services

The goal of this project is to build a practical full-stack application while applying modern software development concepts and best practices.

💻 Running Locally

1. Clone the repository

git clone https://github.com/Aryan1i/CodeDNA.git
cd CodeDNA

2. Run the Backend

Navigate to the backend directory:

cd codedna-backend

Configure the required environment variables and dependencies, then start the backend application.

3. Run the Frontend

Open another terminal and navigate to:

cd codedna-frontend

Install dependencies:

npm install

Start the development server:

npm run dev

The frontend will then be available through the local development URL provided by Vite.
